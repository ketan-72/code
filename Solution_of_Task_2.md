Solution for 2A:

Case 1: m>k

Then the public good is already provided.
Consider any contributor:

If they switch from C → N, the number of contributors becomes m−1≥k

The public good is still provided. They now free-ride, which they strictly prefer.
So every contributor wants to deviate.
Therefore, No profile with more than k contributors can be a PSNE.

Case 2: m=k

Then, The public good is provided. If any contributor deviates to N.
contributors become k−1 public good fails.
they move from:
(provided, contributed)→(not provided, not contributed)
Preference is 2≻3, So contributors do NOT deviate.

Now consider a non-contributor:
If they switch to contribute, public good still provided
they move from:
(provided, not contribute)→(provided, contribute)
Preference is 1≻2, So non-contributors also do NOT deviate.

Therefore, Every action profile with exactly k contributors is a PSNE.

Case 3: m<k.

Then the public good is NOT provided.

Consider any non-contributor:
If they alone switch to contribute, contributors become m+1≤k−1. good still NOT provided
they move from:
(not provided, not contribute)→(not provided, contribute)
Preference is 3≻4, So they do NOT deviate.

Now consider contributors:
If a contributor switches to not contributing, good still not provided
they move from:
(not provided, contribute)→(not provided, not contribute)

Preference is 3≻4, So contributors DO want to deviate.
Therefore, No profile with less than k contributors can be a PSNE.

Solution for 2B (part 2)

case 1 and 2 same as part 1.

Case 3: (k<c≤n)

Payoffs: Stag hunters get S/c, which is strictly less than H.
Any stag hunter can switch to Hare and raise their payoff to H.

Therefore, Not a Nash equilibrium.

Case 4: Optimal Stag range (m≤c≤k)

Stag hunters get S/c>H, Hare hunters get H.
Stag Hunter Deviation: If a stag hunter switches to Hare, they get H, which is a downgrade from S/c. They will stay.

Hare Hunter Deviation: If a Hare hunter switches to Stag, the new count becomes c+1.
If c<k, then c+1≤k. The deviator gets S/c+1>H. This is a profitable deviation, meaning profiles with m≤c<k are unstable.
If c=k, the new count becomes k+1. The deviator gets s/k+1. <H. This means a Hare hunter will not want to join the stag hunt because it dilutes the shares too much.

Hence, c=k is a PSNE.
